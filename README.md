# 젬 모자이크 (Gem Mosaic)

숫자에 맞는 보석을 칸마다 붙여서 픽셀 그림을 완성하는 보석 색칠(컬러 바이 넘버) 퍼즐 게임입니다.
별도 설치나 빌드 없이 `index.html` 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. (PC·모바일 모두 지원)

## 플레이 방법

1. 갤러리에서 그림을 고릅니다.
2. 아래 팔레트에서 번호(색)를 고르면 해당 번호 칸이 강조됩니다.
3. 강조된 칸을 탭하거나 드래그해 보석을 붙입니다. 다른 번호 칸에는 붙지 않습니다.
4. 한 색을 다 붙이면 다음 색으로 자동 전환되고, 모든 칸을 채우면 그림이 완성됩니다.

## 조작

| 동작 | 모바일 | PC |
| --- | --- | --- |
| 보석 붙이기 | 한 손가락 탭 / 드래그 | 왼쪽 클릭 / 드래그 |
| 확대·축소 | 두 손가락 핀치 | 마우스 휠, `+` / `-` |
| 화면 이동 | 두 손가락 드래그, ✋ 이동 모드 | 오른쪽 드래그, `Space` + 드래그 |
| 색 선택 | 팔레트 탭 | 숫자 키 `1`~`9` |
| 힌트 | 💡 버튼 | `H` |
| 전체 보기 | ⛶ 버튼 | `F` |

## 기능

- 9개의 오리지널 그림 (하트, 꽃, 버섯, 고양이, 물고기, 컵케이크, 돛단배, 무지개, 만다라)
- 캔버스로 그린 다면체 보석 렌더링, 붙일 때 튀어나오는 애니메이션과 효과음
- 진행 상황 자동 저장 (브라우저 localStorage)
- 완성 시 반짝임 효과와 보석 파티클
- 라이트/다크 모드 자동 대응

## 그림 추가하기

`index.html`의 `LEVELS` 배열에 항목을 추가하면 됩니다. 문자 하나가 한 칸이고 `.`은 빈 칸이며,
`palette`에 적은 순서대로 1, 2, 3… 번호가 붙습니다.

```js
{ id:'tree', name:'나무',
  palette:{ G:['#22c55e','초록'], N:['#8a5a2b','나무'] },
  art:[
    '.GGG.',
    'GGGGG',
    '..N..' ]},
```
