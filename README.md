# 젬 모자이크 (Gem Mosaic)

픽셀 그림판에 뒤섞여 박힌 보석을 정리해서, 모든 칸을 배경색에 맞는 보석으로 채우는 보석 정렬 퍼즐입니다.
별도 설치나 빌드 없이 `index.html` 하나로 동작합니다. 브라우저로 열면 바로 플레이할 수 있습니다.

## 규칙

- 시작하면 그림의 모든 칸에 보석이 박혀 있고, 배경색과 맞는 보석은 하나도 없습니다(테두리 포함). 아래 **보관함(컨테이너)** 은 비어 있습니다.
- **선택**: 그림판의 잘못 놓인 보석을 탭하면, 붙어 있는 같은 색 보석 묶음이 살짝 떠오르며 선택됩니다. 대각선으로 한 칸만 닿아 있어도 붙어 있는 것으로 봅니다. 같은 묶음을 다시 탭하면 선택이 해제됩니다.
- **비우기**: 묶음을 선택한 상태에서 보관함을 탭하면, 묶음이 보관함으로 내려가고 그 자리가 빈칸이 됩니다.
- **채우기**: 빈칸 배경색과 같은 색 보석(그림판의 묶음이나 보관함의 보석)을 고른 뒤 빈칸을 탭하면, 이어진 빈칸(대각선 포함)에 채워집니다. 빈칸보다 보석이 많아 다 못 옮기면 남은 보석은 선택된 채로 남아서 바로 다른 빈칸을 탭할 수 있습니다.
- **보관함 칸**: 48칸(4줄)으로 시작합니다. 한 가지 배경색 칸을 모두 맞는 보석으로 채우면 자동으로 4칸이 늘어나고, 최대 72칸(6줄)까지입니다. 보관함이 꽉 차도 게임오버는 없습니다.
- 모든 칸이 배경색에 맞게 채워지면 클리어입니다. 그림의 영역 모양은 그대로 두고, 영역(큰 영역은 반·4등분 조각)마다 다른 색 한 가지가 통째로 깔린 상태로 시작합니다. 레벨이 오를수록 조각이 잘게 나뉘어 어려워집니다.

## 기능

- 레벨마다 모두 다른 그림: 1~45레벨은 손으로 그린 그림과 패턴 45개, 46레벨부터는 레벨 번호로 정해지는 그림을 자동으로 만듭니다(패턴 7종 + 캐릭터 2개를 배치한 장면). 같은 레벨은 항상 같은 그림·같은 배치입니다.
- 레벨이 오를수록 보석 칸 수가 늘어납니다. 1~9레벨은 원래 크기이고, 10레벨부터 그림의 긴 변이 16칸에서 2레벨마다 1칸씩 커져 최대 34칸(테두리 포함)까지 커집니다.
- 두 손가락으로 확대·축소(최대 4배)하고, 확대한 상태에서는 한 손가락으로 끌어서 이동합니다. 오른쪽 위 버튼으로 전체 보기로 돌아갑니다. PC에서는 마우스 휠로 확대합니다.
- 보석이 날아가는 애니메이션, 효과음, 클리어 연출
- 진행 상황 자동 저장(브라우저 localStorage): 도달한 레벨, 하던 판의 보석 배치와 보관함까지 저장되어 다음에 열면 이어서 할 수 있습니다.
  같은 기기·같은 브라우저에서만 유지되며, 브라우저 데이터를 지우면 초기화됩니다. 앱 내장 브라우저처럼 저장이 막힌 환경이면 시작할 때 경고가 뜹니다.
- 진행 코드(설정 메뉴): `GEM-0004-J` 같은 코드를 복사해 두면, 저장이 지워지거나 다른 브라우저로 옮겨도 코드를 입력해 도달한 레벨을 되찾을 수 있습니다.
- 레벨 선택(오른쪽 위 버튼): 클리어한 레벨을 골라 다시 플레이할 수 있습니다. 다시 하던 판도 따로 저장되고, 도전 중인 레벨의 진행 상황은 그대로 남습니다.
- 라이트/다크 모드 자동 대응

## 아이폰·안드로이드 홈 화면 앱으로 쓰기 (GitHub Pages)

이 저장소는 웹앱으로 설치할 수 있게 준비되어 있습니다(`manifest.webmanifest`, `sw.js`, `icons/`).
GitHub Pages로 열면 게임이 자기 주소로 직접 열려서 진행 상황이 안정적으로 저장되고, 한 번 열면 오프라인에서도 실행됩니다.
페이지에 `noindex` 표시가 있어 검색 엔진 결과에는 나오지 않고, 주소를 아는 사람만 들어올 수 있습니다.

1. 저장소 **Settings → General** 맨 아래 *Danger Zone*에서 **Change visibility → Public**
2. **Settings → Pages**에서 *Source*를 **Deploy from a branch**, Branch를 `ccr-3c5511f1-5x3i4q` / `/ (root)`로 고르고 **Save**
3. 1~2분 뒤 `https://jiyong7073-tech.github.io/Puzzle-game/` 를 아이폰 **Safari**로 열고 **공유 → 홈 화면에 추가**

## 그림 추가하기

`index.html`의 `PICS` 배열 **맨 끝에** 항목을 추가하면 됩니다(중간에 넣으면 이미 깬 레벨의 그림이 바뀝니다). 한 색이 절반에 가까우면 바깥에 배경이 자동으로 덧대지고, `art`에 `makeArt(w, h, (x, y) => 문자)` 함수를 써서 패턴을 그릴 수도 있습니다. 문자 하나가 한 칸이고, `.` 은 `bg` 색으로 채워지며
바깥에 `frame` 색 테두리가 자동으로 둘러집니다.

```js
{ name:'나무', bg:'#bfe9ff', frame:'#ffd23f',
  palette:{ G:'#22c55e', N:'#8a5a2b' },
  art:[
    '.GGG.',
    'GGGGG',
    '..N..' ]},
```
